# Ferrite

Ferrite is a PowerShell 7 editor for Windows in the spirit of the Windows PowerShell ISE: a native, fast script editor with IntelliSense, an integrated console, a debugger and the ISE's panes and keyboard shortcuts. It adds colour-coded **containers** that keep client work and sign-ins apart, a **Modules** pane that finds and fixes module conflicts, and an optional **Claude Code** pane.
